# Student Management System

A Spring Boot REST API project for managing student records.

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Spring Security (JWT)
- MySQL
- Maven
- Docker
- Swagger (OpenAPI)
- JUnit 5
- Mockito
- Git & GitHub

## Features

- User Authentication (JWT)
- Role-Based Authorization
- CRUD Operations
- Validation
- Global Exception Handling
- Pagination & Sorting
- Advanced Search
- Swagger API Documentation
- Unit Testing
- Docker Support

## Run Locally

### Clone the repository

```bash
git clone https://github.com/geelaniasif-dev/student-management-system
```

### Build

```bash
mvn clean install
```

### Run

```bash
mvn spring-boot:run
```
